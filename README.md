# Mathematical Games: A High School Thought!
Narrated by Armita, Written by GPT!

## The Story Behind This Project

Years ago, we had a mathematics Olympiad class (Farzanegan 2, Tehran, Iran) in a small basement room. I don't remember all the details, but there was one problem that fascinated me.

Imagine placing *n* lanterns at arbitrary positions on a plane. Each lantern illuminates a particular angle, and it can rotate freely through 360 degrees. If the sum of all the illumination angles is 360 degrees, can we always rotate the lanterns so that they illuminate the entire plane, regardless of their positions and individual angles?

I believe the problem had a beautiful proof, possibly using induction. But what stayed with me was more than the mathematics itself: **I saw the potential to turn a mathematical problem into a game.**

I imagined building an application where people could explore mathematical ideas through interactive challenges. Not just conventional puzzles, but problems with elegant mathematical foundations, creative solutions, and room for experimentation.

Websites like Brilliant.org have explored mathematical learning through interactive problems and demonstrations. My idea was to take a somewhat different direction: create playful games inspired by mathematical theorems, proofs, and intriguing questions.

At the time, this was just a thought or a light dream! Now, with the rapid progress of AI, I feel that bringing some of these ideas to life has become more achievable.

This project is my first step toward exploring that dream.

## About This Project

This repository contains an interactive implementation of the lantern problem, along with the HTML code used to explore it.

The goal is to make mathematical ideas tangible through experimentation and play, while exploring how mathematical reasoning can inspire engaging games.

This is the beginning of a broader idea: **turning beautiful mathematical problems into interactive experiences.**
